description: Analyze codebase and generate prioritized task backlog
---

Activate the task-discovery skill to analyze the finans codebase, identify gaps between current implementation and CLAUDE.md specifications, and generate a comprehensive, prioritized, and numbered task backlog.

The discovery agent will:
1. Analyze codebase structure and implementation state
2. Compare against CLAUDE.md feature descriptions
3. Review existing tasks in .task-board/backlog/
4. Generate new tasks for missing features, refactors, and improvements
5. Enhance existing tasks with better details
6. Assign sequential numbers to all tasks based on priority
7. Apply quality bar (only obvious, valuable work)

Run this command when you want to refresh the project backlog with a comprehensive analysis.

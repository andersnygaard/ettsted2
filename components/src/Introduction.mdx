# Finans Components

Welcome to the Finans component library. This Storybook documents all shared React components used across the Finans application.

## Structure

Components are organized by category:

- **UI** - Core UI components (buttons, cards, inputs, etc.)
- **Forms** - Form input components with validation
- **Data** - Data display components (tables, lists, etc.)
- **Layout** - Layout components (containers, grids, etc.)
- **Charts** - D3.js chart components for visualizations
- **System** - System components (error boundaries, toasts, etc.)
- **Utils** - Utility functions and helpers

## Design System

Finans uses the **Nordic Minimal** design system featuring:

- **Color Palette**: Warm, muted tones (bone, sage, terracotta)
- **Typography**:
  - Headings: Cormorant Garamond (serif)
  - Body: DM Sans (sans-serif)
  - Data: JetBrains Mono (monospace)
- **Styling**: BeerCSS + Material UI integration

## Getting Started

Browse the stories in the sidebar to explore components. Each story demonstrates:

- Component props and variations
- Usage examples
- Interaction patterns
- Accessibility features

## Contributing

When adding new components:

1. Create component file in appropriate category
2. Create corresponding `.stories.tsx` file
3. Document props and usage
4. Add interaction tests where appropriate
5. Ensure accessibility compliance
